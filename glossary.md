# glossary

- **geo** — generative engine optimization
- **aeo / llmo** — same thing, older/newer names
- **ai overviews** — google's generative answer at top of serp
- **ai mode** — google's full generative search
- **citation share** — % of answers citing your url
- **mention share** — % of answers naming your brand
- **answer presence** — binary: in the answer or not
- **fact density** — specific claims per paragraph. #1 lever.
- **llms.txt** — markdown file at site root for ai crawlers. [llmstxt.org](https://llmstxt.org/)
- **mcp** — anthropic's protocol for models ↔ tools/docs. [modelcontextprotocol.io](https://modelcontextprotocol.io/)
- **gptbot / claude-web / perplexitybot / google-extended** — ai crawler user-agents. control via robots.txt.
- **grounding** — model attaching sources to claims
- **rag** — retrieve → synthesize → cite
- **coding agent** — cursor, claude code, copilot, devin. new buyer.
- **prompt tracking** — scheduled runs of fixed prompts to measure drift
- **geo-bench** — princeton benchmark, ~10k queries, 9 domains. [arxiv 2311.09735](https://arxiv.org/abs/2311.09735)

# geo vs seo

| | seo | geo |
|---|---|---|
| surface | 10 links | one answer |
| signal | backlinks, pagerank | facts, entities, citations, freshness |
| metric | rank, clicks | citation share, accuracy |
| competitor | serp neighbors | sources in same answer |
| unit | keyword → page | prompt → fact |
| iteration | weeks | days |

## carries over

- clean html, canonical urls, structured data, speed
- depth and authority
- backlinks (as a learned authority proxy)

## new

- entities > keywords (schema.org, json-ld)
- fact density = #1 lever ([princeton paper](https://arxiv.org/abs/2311.09735))
- cite primary sources inside your own content
- llms.txt
- reddit, hn, youtube, github are first-class citation sources

## dead

- keyword stuffing
- doorway pages
- "longer than competitor" without facts
- gated docs (uncrawlable = uncitable)

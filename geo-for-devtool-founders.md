# geo for devtool founders

devtools have the biggest geo tailwind.

- devs ask llms first. stackoverflow traffic down ~50% since 2022.
- coding agents (cursor, claude code, copilot) pick packages. agent = buyer.
- your docs are already fact-dense. you have the raw material.

## two jobs

| job | surface | fails when |
|-----|---------|------------|
| discovery | "best x for y" | not shortlisted |
| execution | "write code with x" | wrong version/runtime, build fails |

optimize both. being shortlisted is useless if the agent installs the wrong version.

## publish

- compatibility matrix: package × api × runtime × support
- quickstart that runs in a fresh container, no edits
- comparison page with real limits, no superlatives
- migration guide from top 2 competitors
- llms.txt at root. [llmstxt.org](https://llmstxt.org/)

## track

- prompts you want to own (buyer, compare, execute, edge)
- which models cite you
- which sources beat you (reddit, competitor docs, hn)
- factual errors about you

## don't

- buy "ai seo" rewrites
- ignore reddit — perplexity cites it 47% of the time
- publish ai slop — low fact density gets filtered
- mock geo tracking. live data only.

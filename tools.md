## how to pick

1. track or fix? below $5k mrr of ai pipeline, track only. above, buy fixes.
2. care about coding agents separately? use gauge or build an eval harness.
3. can you see the raw answer + url + prompt variant? if not, reject.
4. does it match a manual chatgpt query? if not, reject.
5. price only matters once scope matches.

## diy baseline

- sheet: prompts × engines × date
- free tiers of chatgpt, perplexity, claude, google ai mode
- 2 hours/month

upgrade when manual breaks (~50 prompts × 4 engines × weekly).
